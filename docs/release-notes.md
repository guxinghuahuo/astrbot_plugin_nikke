# NIKKE 资讯助手 v1.3.0

新增本地基地与红球查询，无需联网或账号：

- `/nikke 基地等级 533`：显示满学院的信用点、战斗数据、芯尘每小时产出。
- `/nikke 红球 h48-32`：默认普通全通，困难已通关 48-32。
- `/nikke 红球 33-23 h18-32`：指定普通和困难进度，也可将参数换序。

困难进度必须带 h 前缀；省略普通进度时使用内置表最后一关 50-36。查询结果只显示数值，固定纯文字，不使用 t2i，不添加来源、日期和说明。模糊写法和错误参数只提示正确用法。

沿用已有配置及数据目录，安装后重载插件。下载 `astrbot_plugin_nikke-v1.3.0.zip` 并通过插件管理上传，校验值见 `.sha256` 附件。
