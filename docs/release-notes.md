# NIKKE 资讯助手 v1.3.1

新增角色技能函数工具，供支持工具调用的聊天模型按需查询：

- 工具名：`nikke_query_character_skills(character_name, skill_level=10)`。
- 按国际服角色中文名查询技能1、技能2和爆裂技能，支持1至10级，默认10级，仅含基础技能，不包含珍藏品强化。
- 复用 BlaBlaLink 国际服繁中资料、简繁转换和24小时缓存；刷新失败时保留旧缓存提示，无需账号或 Cookie。
- 群聊、私聊均可调用，无需资讯订阅；只返回文字资料给模型组织回答，不直接发送图片。

使用时开启「聊天查询工具 → 允许模型查询角色技能」（默认关闭），并在 AstrBot 中允许使用该工具。例如提问“拉毗：小红帽7级技能的倍率是多少？”。名称歧义、错误参数和资料读取失败均返回明确提示。

沿用已有配置及数据目录，安装后重载插件。下载 `astrbot_plugin_nikke-v1.3.1.zip` 并通过插件管理上传，校验值见 `.sha256` 附件。
