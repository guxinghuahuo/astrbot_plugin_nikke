# NIKKE 资讯助手 v1.1.0

新增国际服角色与技能查询，直接读取 BlaBlaLink 官方繁中 CDN，本地转为简体，保留国际服术语，无需账号、Cookie、RSSHub 或模型。

- `/nikke 角色 小红帽`：基础属性、武器参数及技能名称。
- `/nikke 技能 小红帽`：三个基础技能，默认 10 级。
- `/nikke 技能 拉毗：小红帽 7`：指定 1–10 级技能数值。
- 支持简繁输入、部分名称匹配和歧义提示；资料缓存 24 小时，刷新失败时明确标注旧缓存。
- 新增「基础配置 → 角色与技能图片回复」开关，默认关闭。开启后复用 AstrBot 配置的 t2i 服务，将技能合并为卡片，过长时自动分页。渲染失败只返回简短提示。

当前技能为基础版本，不含珍藏品强化。图片回复请先在 AstrBot 配置中填写本地 t2i 服务地址；插件不会更改该地址。角色 CDN 可复用现有「国际服图片代理」。

沿用已有插件标识、配置和数据目录。升级前备份配置与数据，安装后重载插件；无需重新配置资讯订阅。资讯推送仍要求 AstrBot `>=4.10.4`、OneBot v11 和可访问的 RSSHub。

下载 `astrbot_plugin_nikke-v1.1.0.zip` 后通过 AstrBot 插件管理页上传，或从仓库链接安装。校验值见随附的 `.sha256` 文件。详细配置和图片效果见 README。
