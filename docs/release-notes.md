# NIKKE 资讯助手 v1.4.2

新增「国际服非中文动态翻译 → 过滤翻译推广信息与标签」，默认开启，仅在翻译启用时生效。

翻译前清理常见中英日韩下载/商店、官方社区引流、应用内购买免责声明、版权尾注和话题标签。保留剧情正文、活动规则、奖励、兑换码、视频链接、动态原链接与配图。采用常见模板规则，不会因为正文提到商店、购买或下载就删除整段内容；非标准推广写法可能保留。

关闭开关可翻译完整原文。原始存档不修改，切换开关后预览使用独立缓存，已发送动态不重新推送。保留 v1.4.1 的国际服代理回退功能。
