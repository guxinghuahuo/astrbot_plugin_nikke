# NIKKE 资讯助手 v1.3.2

角色技能查询增加珍藏品阶段支持，更新图片页脚及 README 首页。

- `/nikke 技能 拉普拉斯 珍藏品1`：查询10级技能，珍藏品阶段1。
- `/nikke 技能 拉普拉斯 7 珍藏品3`：查询7级技能，珍藏品阶段3。
- 不填珍藏品参数仍查询基础技能；强化按阶段累积解锁，结果标明各技能的强化状态。
- `nikke_query_character_skills` 增加 `treasure_phase` 参数，0为基础技能，1至3为珍藏品阶段，默认0。
- 珍藏品复用 BlaBlaLink 繁中公开资料、简繁转换、24小时缓存与可选图片回复，无需账号或 Cookie。
- t2i 图片页脚改为「项目作者：@孤行花火」、GitHub 项目地址及 Star 提示。基础技能限制、珍藏品阶段和旧缓存提示保留在正文区域。
- README 增加居中标题、版本徽章、快捷导航和并排效果预览，更新角色技能图片回复示例。

沿用已有配置及数据目录，安装后重载插件。模型工具需开启「聊天查询工具 → 允许模型查询角色技能」，并在 AstrBot 中允许使用工具。

下载 `astrbot_plugin_nikke-v1.3.2.zip` 并通过插件管理上传，校验值见 `.sha256` 附件。
