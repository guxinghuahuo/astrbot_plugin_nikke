# NIKKE 资讯助手 v1.3.3

补全官方动态与日历的故障日志，修复官方动态特殊字符导致的解析失败。

- 失败时以 WARNING 记录诊断编号、请求地址、耗时、失败阶段、HTTP 状态、关键响应头，以及完整异常链和调用栈，无须开启 DEBUG。
- 失败请求的原始响应正文分段记录，通过相同编号关联；控制字符转义显示，非 UTF-8 内容使用 Base64 保留。凭据字段脱敏，正文最多保留 4 MiB，超限或中断明确标为不完整，未收到响应时单独说明。
- 错误摘要区分 DNS、TLS、连接中断、请求超时、响应体传输、编码和 JSON 解析失败。
- 官方动态正文中的 U+000B 等字符转换为文本分隔，避免内部 XML 解析失败导致整批动态无法获取。
- 增加原始响应还原、日志分段、凭据脱敏、异常分类与任务取消的回归测试。

沿用已有配置及数据目录，安装后重载插件。动态与日历接口仍直连，不使用国际服图片代理；历史日志留存随 AstrBot 或容器日志的保留设置执行。

下载 `astrbot_plugin_nikke-v1.3.3.zip` 并通过插件管理上传，校验值见 `.sha256` 附件。
